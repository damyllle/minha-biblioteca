# 📚 Minha Biblioteca

Aplicação web desenvolvida para cadastro, consulta e gerenciamento de livros, com foco em tecnologia e programação.

## 🚀 Sobre o projeto

O Minha Biblioteca é um projeto de estudos que busca colocar em prática conhecimentos de desenvolvimento backend e frontend, permitindo organizar e consultar livros por meio de uma aplicação web.

## 🛠️ Tecnologias utilizadas

- Java
- Spring Boot
- HTML
- CSS
- Banco de dados SQL

## 🎯 Objetivo

Praticar conceitos de programação Java, desenvolvimento de APIs, integração com banco de dados e construção de interfaces web.

## 👩‍💻 Desenvolvimento

Projeto desenvolvido como parte da minha jornada de aprendizado em Ciência da Computação, com foco na evolução das minhas habilidades em desenvolvimento de software.*
